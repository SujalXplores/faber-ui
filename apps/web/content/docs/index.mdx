Faber UI is a component library built on [shadcn/ui](https://ui.shadcn.com), [Base UI](https://base-ui.com), and Tailwind CSS v4. It is copy-paste friendly, RTL-ready, and designed to be instantly familiar to anyone who has used shadcn before.

## How it works

Components are copied into your project by the shadcn CLI, so you own the
source and can edit any of them. The first component you add also copies the
theme, the tokens and motion utilities every component uses, into
`styles/faber/`. [Getting Started](/docs/getting-started) walks through both.

```npm
npx shadcn@latest add https://faber-ui.vercel.app/r/dialog.json
```

```tsx
import { Button } from "@/components/ui/button";

export default function Example() {
  return <Button>Click me</Button>;
}
```

Head to the [Components](/docs/components/button) section to explore each component, its variants, and its API.
