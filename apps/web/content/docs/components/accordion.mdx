import {
  Accordion,
  AccordionContent,
  AccordionItem,
  AccordionTrigger,
} from "@workspace/ui/components/accordion";

`Accordion` is built on the Base UI `Accordion` primitive. It renders a vertically stacked set of expandable sections with animated open/close transitions.

## Installation

```bash
cd packages/ui
pnpm dlx shadcn@latest add accordion
```

## Usage

```tsx
import {
  Accordion,
  AccordionContent,
  AccordionItem,
  AccordionTrigger,
} from "@workspace/ui/components/accordion";

export default function Example() {
  return (
    <Accordion>
      <AccordionItem value="item-1">
        <AccordionTrigger>Is it accessible?</AccordionTrigger>
        <AccordionContent>Yes. It adheres to WAI-ARIA standards.</AccordionContent>
      </AccordionItem>
    </Accordion>
  );
}
```

## API

| Component          | Description                                           |
| ------------------ | ----------------------------------------------------- |
| `Accordion`        | Root container. Accepts Base UI Accordion Root props. |
| `AccordionItem`    | A single collapsible section. Accepts `value`.        |
| `AccordionTrigger` | The clickable header that toggles the section.        |
| `AccordionContent` | The expandable content area.                          |
