import { buttonWithIcon, buttonAsLink } from "@/examples/button";

`Button` is built on the Base UI `Button` primitive and exposes a shadcn-compatible variant API through `class-variance-authority`. It supports a `render` prop for composition (the Base UI equivalent of `asChild`).

## Installation

```npm
npx shadcn@latest add https://faber-ui.vercel.app/r/button.json
```

## Usage

```tsx
import { Button } from "@/components/ui/button";

export default function Example() {
  return <Button>Button</Button>;
}
```

### With an icon

Buttons automatically size and space child SVG icons. Drop a Remixicon component inside:

<Preview
  code={buttonWithIcon}
>
  <Button>Continue<RiArrowRightLine /></Button>
</Preview>

### As a link

Navigation belongs on a link, not a button, so apply `buttonVariants` to the link itself. Base UI's `Button` enforces button semantics, which a link must not take on.

<Preview
  code={buttonAsLink}
>
  <a href="/docs" className={buttonVariants()}>Go to docs</a>
</Preview>
