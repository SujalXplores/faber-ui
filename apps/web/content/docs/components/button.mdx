`Button` is built on the Base UI `Button` primitive and exposes a shadcn-compatible variant API through `class-variance-authority`. It supports a `render` prop for composition (the Base UI equivalent of `asChild`).

## Installation

```bash
cd packages/ui
pnpm dlx shadcn@latest add button
```

## Usage

```tsx
import { Button } from "@workspace/ui/components/button";

export default function Example() {
  return <Button>Button</Button>;
}
```

### With an icon

Buttons automatically size and space child SVG icons. Drop a Remixicon component inside:

<Preview
  code={`import { RiArrowRightLine } from "@remixicon/react";
import { Button } from "@workspace/ui/components/button";

export default function Example() {
  return (
    <Button>
      Continue
      <RiArrowRightLine />
    </Button>
  );
}`}
>
  <Button>
    Continue
    <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="currentColor" className="size-3.5"><path d="M16.172 11l-5.364-5.364 1.414-1.414L20 12l-7.778 7.778-1.414-1.414L16.172 13H4v-2z"/></svg>
  </Button>
</Preview>

### As a link

Use the `render` prop to render the button styles on a different element, such as a Next.js `Link`:

<Preview
  code={`import Link from "next/link";
import { Button } from "@workspace/ui/components/button";

export default function Example() {
  return (
    <Button render={<Link href="/docs" />}>
      Go to docs
    </Button>
  );
}`}
>
  <Button nativeButton={false} render={<a href="/docs" />}>Go to docs</Button>
</Preview>
