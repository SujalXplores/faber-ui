import {
  ContextMenu,
  ContextMenuCheckboxItem,
  ContextMenuContent,
  ContextMenuItem,
  ContextMenuLabel,
  ContextMenuRadioGroup,
  ContextMenuRadioItem,
  ContextMenuSeparator,
  ContextMenuShortcut,
  ContextMenuSub,
  ContextMenuSubContent,
  ContextMenuSubTrigger,
  ContextMenuTrigger,
} from "@workspace/ui/components/context-menu";

`ContextMenu` is built on the Base UI `Menu` primitive. It displays a menu of actions when the user right-clicks a trigger element.

## Installation

```bash
cd packages/ui
pnpm dlx shadcn@latest add context-menu
```

## Usage

```tsx
"use client";

import {
  ContextMenu,
  ContextMenuContent,
  ContextMenuItem,
  ContextMenuTrigger,
} from "@workspace/ui/components/context-menu";

export default function Example() {
  return (
    <ContextMenu>
      <ContextMenuTrigger>Right click here</ContextMenuTrigger>
      <ContextMenuContent>
        <ContextMenuItem>Back</ContextMenuItem>
        <ContextMenuItem>Forward</ContextMenuItem>
      </ContextMenuContent>
    </ContextMenu>
  );
}
```

## API

| Component                 | Description                                                                          |
| ------------------------- | ------------------------------------------------------------------------------------ |
| `ContextMenu`             | Root.                                                                                |
| `ContextMenuTrigger`      | The element that opens the menu on right click.                                      |
| `ContextMenuContent`      | The menu popup.                                                                      |
| `ContextMenuItem`         | A menu action. Accepts `variant?: "default" \| "destructive"` and `inset?: boolean`. |
| `ContextMenuCheckboxItem` | A toggleable item with a check indicator.                                            |
| `ContextMenuRadioItem`    | A radio option. Use inside `ContextMenuRadioGroup`.                                  |
| `ContextMenuRadioGroup`   | Groups radio items.                                                                  |
| `ContextMenuLabel`        | Non-interactive label.                                                               |
| `ContextMenuSeparator`    | Horizontal divider.                                                                  |
| `ContextMenuShortcut`     | Right-aligned shortcut hint.                                                         |
| `ContextMenuGroup`        | Logical grouping of items.                                                           |
| `ContextMenuSub`          | Submenu container.                                                                   |
| `ContextMenuSubTrigger`   | Opens the submenu.                                                                   |
| `ContextMenuSubContent`   | The submenu popup.                                                                   |
