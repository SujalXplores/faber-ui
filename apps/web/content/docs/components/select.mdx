import {
  Select,
  SelectContent,
  SelectGroup,
  SelectItem,
  SelectLabel,
  SelectTrigger,
  SelectValue,
} from "@workspace/ui/components/select";

`Select` is built on the Base UI `Select` primitive. It renders a custom dropdown for choosing a single value from a list.

## Installation

```bash
cd packages/ui
pnpm dlx shadcn@latest add select
```

## Usage

```tsx
"use client";

import {
  Select,
  SelectContent,
  SelectItem,
  SelectTrigger,
  SelectValue,
} from "@workspace/ui/components/select";

export default function Example() {
  return (
    <Select>
      <SelectTrigger>
        <SelectValue placeholder="Select a fruit" />
      </SelectTrigger>
      <SelectContent>
        <SelectItem value="apple">Apple</SelectItem>
        <SelectItem value="banana">Banana</SelectItem>
      </SelectContent>
    </Select>
  );
}
```

## API

| Component                | Description                                             |
| ------------------------ | ------------------------------------------------------- |
| `Select`                 | Root. Accepts `value`, `defaultValue`, `onValueChange`. |
| `SelectTrigger`          | The trigger button. Accepts `size?: "sm" \| "default"`. |
| `SelectValue`            | Displays the selected value or placeholder.             |
| `SelectContent`          | The dropdown popup.                                     |
| `SelectItem`             | A single option. Accepts `value`.                       |
| `SelectGroup`            | Groups related items.                                   |
| `SelectLabel`            | Non-interactive label for a group.                      |
| `SelectSeparator`        | Horizontal divider.                                     |
| `SelectScrollUpButton`   | Scroll indicator for long lists (up).                   |
| `SelectScrollDownButton` | Scroll indicator for long lists (down).                 |
