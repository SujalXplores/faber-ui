`Sonner` is built on the [`sonner`](https://sonner.emilkowal.ski) library. The `Toaster` component sets up the viewport, and the `toast` function (imported from `sonner`) triggers notifications programmatically.

## Installation

```npm
npx shadcn@latest add https://faber-ui.vercel.app/r/sonner.json
```

## Usage

Add the `Toaster` to your root layout, then call `toast()` anywhere in a client component:

```tsx
"use client";

import { Toaster } from "@workspace/ui/components/sonner";
import { toast } from "sonner";

export default function Layout({ children }: { children: React.ReactNode }) {
  return (
    <>
      {children}
      <Toaster />
    </>
  );
}

// anywhere in a client component
function MyButton() {
  return <button onClick={() => toast("Event has been created")}>Show toast</button>;
}
```

### Types

The `toast` function accepts a `type` option that renders an icon:

```tsx
toast.success("Saved");
toast.info("Heads up");
toast.warning("Warning");
toast.error("Failed");
toast.loading("Loading");
toast.promise(myAsyncFn, { success: "Done", error: "Failed" });
```

## API

| Component | Description                                                           |
| --------- | --------------------------------------------------------------------- |
| `Toaster` | The viewport. Drop it in your layout once.                            |
| `toast`   | The trigger function (imported from `sonner`). Call `toast(message)`. |
