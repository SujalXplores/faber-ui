import {
  DirectionProvider,
  useDirection,
} from "@workspace/ui/components/direction";

`Direction` is a thin re-export of the Base UI direction provider. It sets the text direction (LTR or RTL) for a subtree and exposes a `useDirection` hook to read the current value.

## Installation

```bash
cd packages/ui
pnpm dlx shadcn@latest add direction
```

## Usage

```tsx
"use client";

import {
  DirectionProvider,
  useDirection,
} from "@workspace/ui/components/direction";

export default function Example() {
  return (
    <DirectionProvider dir="rtl">
      <Content />
    </DirectionProvider>
  );
}

function Content() {
  const direction = useDirection();
  return <p>Current direction: {direction}</p>;
}
```

## API

| Component           | Description                                                |
| ------------------- | ---------------------------------------------------------- |
| `DirectionProvider` | Sets the direction for its children. Accepts `dir`.        |
| `useDirection`      | Hook returning the current direction (`"ltr"` or `"rtl"`). |
