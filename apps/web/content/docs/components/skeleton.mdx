import { Skeleton } from "@workspace/ui/components/skeleton";

`Skeleton` renders a muted, pulsing block. Use it to reserve space while data is loading.

## Installation

```npm
npx shadcn@latest add https://faber-ui.vercel.app/r/skeleton.json
```

## Usage

```tsx
import { Skeleton } from "@workspace/ui/components/skeleton";

export default function Example() {
  return <Skeleton className="h-4 w-48" />;
}
```

## Examples

### Profile card

<div className="not-prose demo flex items-center gap-4">
  <Skeleton className="size-12 rounded-full" />
  <div className="flex flex-col gap-2">
    <Skeleton className="h-4 w-48" />

</div>

### Single line

<div className="not-prose demo">
  <Skeleton className="h-4 w-full" />
</div>

## API

The `Skeleton` accepts all props of a native `<div>` element. Control the size and shape with `className`.
