import {
  Menubar,
  MenubarCheckboxItem,
  MenubarContent,
  MenubarGroup,
  MenubarItem,
  MenubarLabel,
  MenubarMenu,
  MenubarRadioGroup,
  MenubarRadioItem,
  MenubarSeparator,
  MenubarShortcut,
  MenubarSub,
  MenubarSubContent,
  MenubarSubTrigger,
  MenubarTrigger,
} from "@workspace/ui/components/menubar";

`Menubar` is built on the Base UI `Menu` primitive. It renders a horizontal bar of menus, each opening a dropdown of actions.

## Installation

```bash
cd packages/ui
pnpm dlx shadcn@latest add menubar
```

## Usage

```tsx
"use client";

import {
  Menubar,
  MenubarContent,
  MenubarItem,
  MenubarMenu,
  MenubarTrigger,
} from "@workspace/ui/components/menubar";

export default function Example() {
  return (
    <Menubar>
      <MenubarMenu>
        <MenubarTrigger>File</MenubarTrigger>
        <MenubarContent>
          <MenubarItem>New Tab</MenubarItem>
          <MenubarItem>Open</MenubarItem>
        </MenubarContent>
      </MenubarMenu>
    </Menubar>
  );
}
```

## API

| Component             | Description                                                                          |
| --------------------- | ------------------------------------------------------------------------------------ |
| `Menubar`             | Root bar.                                                                            |
| `MenubarMenu`         | A single menu within the bar.                                                        |
| `MenubarTrigger`      | The button that opens the menu. Use `render`.                                        |
| `MenubarContent`      | The menu popup.                                                                      |
| `MenubarGroup`        | Logical grouping of items.                                                           |
| `MenubarItem`         | A menu action. Accepts `variant?: "default" \| "destructive"` and `inset?: boolean`. |
| `MenubarLabel`        | Non-interactive label. Accepts `inset`.                                              |
| `MenubarSeparator`    | Horizontal divider.                                                                  |
| `MenubarShortcut`     | Right-aligned shortcut hint.                                                         |
| `MenubarCheckboxItem` | A toggleable item with a check indicator.                                            |
| `MenubarRadioGroup`   | Groups radio items. Accepts `value`.                                                 |
| `MenubarRadioItem`    | A radio option.                                                                      |
| `MenubarSub`          | Submenu container.                                                                   |
| `MenubarSubTrigger`   | Opens the submenu.                                                                   |
| `MenubarSubContent`   | The submenu popup.                                                                   |
| `MenubarPortal`       | Portals the content out of the DOM tree.                                             |
