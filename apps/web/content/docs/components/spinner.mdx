`Spinner` renders a spinning Remixicon loader. It is a pure SVG element with `role="status"` and an `aria-label` of "Loading".

## Installation

```bash
cd packages/ui
pnpm dlx shadcn@latest add spinner
```

## Usage

```tsx
import { Spinner } from "@workspace/ui/components/spinner";

export default function Example() {
  return <Spinner />;
}
```

## Examples

### Default

<div className="not-prose demo flex items-center gap-4">

<div className="not-prose demo flex items-center gap-4">

## API

The `Spinner` accepts all props of an `<svg>` element except `children`. Control the size with `className`.
